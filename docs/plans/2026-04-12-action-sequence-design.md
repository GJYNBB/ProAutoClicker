# 专业连点器动作序列设计

## 目标

这一版把原本的单动作连点器升级为支持动作序列、随机化参数、暗黑/浅色主题、HUD 可拖拽和更完整校验逻辑的桌面工具。

## 核心设计

- 底层统一为 `ActionUnit` 列表，单动作模式本质上是只有 1 个动作单元的序列。
- `ActionUnit` 独立保存鼠标/键盘动作、点击类型、目标模式、随机间隔、随机按住时长、坐标抖动、执行次数/时长和完成后等待时间。
- `AppSettings` 负责热键、热键范围、整套序列模式和动作列表。
- 第 1 个动作单元继续通过主界面“快速设置”编辑，高级页负责新增、复制、删除和排序整个动作序列。
- 控制器拆成“整套序列循环”和“单动作单元执行”两层，支持单轮执行和整套循环。

## UI 方向

- 主窗口拆成“快速设置”“高级动作序列”“运行与帮助”三个标签页，避免一屏过载。
- 新增动作通过弹窗编辑，主界面的快速设置始终同步第 1 步。
- 提供浅色 / 暗黑主题切换。
- HUD 支持状态、步骤、频率、次数四类内容的自由勾选，并支持拖拽定位。
- 校验失败时使用红色边框和集中错误信息双重提示。

## 边界约束

- 持续运行仅适用于单动作任务；一旦动作序列有多步，第 1 步必须改成固定次数或固定时长。
- 鼠标目标的“启动后记录当前位置”在每次开始该动作单元时重新读取。
- 键盘动作和热键之间保持冲突校验，避免开始/退出热键与动作键完全相同。
